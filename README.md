# 旅游足迹分享社区 / Travel Footprint Community



## 项目简介 / Project Introduction

中文：
一个完整的用户生成内容（UGC）旅游分享平台。用户可以注册登录、发布旅行游记、上传图片和 GPX 路线图，并可在帖子下留言点赞，形成活跃的旅行爱好者社区。

English:
A complete user-generated content (UGC) travel sharing platform. Users can **register and log in**, post travel stories, upload **photos and GPX route files**, and **comment and like** on posts, forming an active community for travel enthusiasts.

---

## 核心功能 / Core Features

- 用户系统 / User System:注册 / 登录 / 个人主页管理
- 内容发布 / Content Publishing: 文字 + 图片 + GPX 路线图上传
- 社交互动 / Social Interaction: 帖子留言 · 点赞 · 评论回复
- 浏览体验 / Browsing: 按目的地 / 时间筛选查看他人游记

---

## 技术栈 / Tech Stack

-前端 / Frontend: HTML5, CSS3, JavaScript
- 开发工具 / Tools: VSCode, Dreamweaver
- 数据存储 / Data:本地存储 / 后续可接入后端数据库

## 未来改进 / Future Improvements
